RouteMind

Mobile (Flutter) • Web Admin • Serveur Django

Projet privé — Non publié sur les stores

RouteMind est une solution d'envergure développée comme projet privé (usage professionnel interne, non publié sur les stores publics) pour la gestion intelligente de flottes de transport, la planification de tournées et le suivi des conducteurs. Elle combine une application mobile Flutter pour les chauffeurs, une console web de dispatching et un puissant backend en Python/Django.
